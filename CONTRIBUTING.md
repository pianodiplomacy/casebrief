# Contributing

Start by running the [offline judge path](docs/RUNBOOK.md) and inspecting the [Five-Gate Architecture](docs/ARCHITECTURE.md).

Useful contributions include synthetic failure cases, offline tests, and clear documentation. Keep examples synthetic and respect the repository's Apache License 2.0.

Never contribute secrets, private reasoning, customer evidence, confidential case material, or private evaluator content. Do not make unauthorised live inference requests, silently repair an artifact before scoring, or automate consequential decisions.
